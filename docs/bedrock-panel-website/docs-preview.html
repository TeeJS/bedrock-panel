Your setup starts with software.

Run on a compatible Windows PC, then choose the apps, actions, and dashboards you want nearby. A touchscreen or knob is optional.

  1. Download the current release.

    Choose a Windows package from the download page.

  2. Choose your setup.

    Start with a desktop window or follow the guide for your compatible display.

  3. Create a page.

    Use the editor to arrange a grid, add an app, or display a web dashboard.
