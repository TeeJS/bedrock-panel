A few things to know.

No dedicated hardware required.

Software mode runs in a desktop window on a compatible Windows PC.

Using a touchscreen?

Check its layout and input setup in the hardware guides. A 1920×480 canvas is the starting point for panel pages; supported configurations need to be checked for your setup.

Building your own?

The Bedrock Console is a DIY touchscreen build with an optional knob.

Read before updating.

Review the release notes and setup guidance for the package you choose.
