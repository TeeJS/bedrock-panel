A few good questions

Before you start.

Can I use it without a touchscreen?

Yes. Software mode runs in a desktop window on a compatible Windows PC. A touchscreen or knob is optional.

Is Bedrock Panel for Windows?

The current release targets Windows. Check the download page for verified system requirements.

Does it need an internet connection?

Local controls and online integrations have different requirements. Web dashboards and connected services need their own network access. See each integration’s guide.

Is it free?

The project is available under MIT, except the QUAKE/ARIS-68 driver, which uses PolyForm Noncommercial. External services may have their own costs.

How do I get help?

Start with the documentation or bring your question to Discord.
