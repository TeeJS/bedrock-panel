## 2. What it is (provenance — docs/About context, NOT a Home section)

*(Per design: QUAKE origin stays in project history and legal/compatibility details,
away from the hero. Use in /docs intro, About page, or meta context.)*

A device-independent launcher and control platform for Windows. Run it
software-only, on a compatible touchscreen, or with optional controllers.
Bedrock Panel grew out of the open-quake community project for the QUAKE panel —
today it is a standalone platform for any compatible setup.

*(This is the one and only place "open-quake" appears on the site.)*

## 5. Ways to make it yours

*(Three equal columns on desktop; stack on mobile. Link detailed display/controller
compatibility and run modes from here — do not promise monitor mode works on every device.)*

**Desktop software** — A compatible Windows PC is all you need. Install, launch,
done.

**Compatible touchscreen** — Run the same software on a touchscreen display with
compatible dimensions for the full hands-on experience. Verified dimensions and
scaling are listed on /download and /docs.

**DIY Bedrock Console** — A complete DIY build: 1920x480 touchscreen console with
an optional knob. Hardware, enclosure, and firmware are open source — build it
yourself. Link: https://github.com/TeeJS/bedrock-console-hardware

*Note beneath the columns (optional controllers, not a run mode): The DK-QUAKE /
ARIS-68 panel and the open Bedrock RP2040 knob work as first-class controllers
when present — nothing requires them.*

## 8. FAQ

**Can I use it without a touchscreen?**
Yes. Software mode runs on a compatible Windows PC with no hardware at all.
A touchscreen or knob adds the hands-on layer.

**Which computers does it run on?**
Windows today, with macOS and Linux ports coming soon.

**Does it need internet?**
The core launcher works offline. Some apps — AI voice, translation, meeting
transcription — need an internet connection.

**Is it free?**
Yes, it's free and open source. Nearly everything is MIT licensed; the QUAKE
driver is PolyForm Noncommercial.

**How do I get help?**
Start on Discord — the community and maintainers hang out there.
