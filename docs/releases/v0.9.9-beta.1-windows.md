# Bedrock Panel v0.9.9-beta.1 — Windows beta: voice fixes

This beta fixes voice problems found in daily use: AI Voice sending things nobody said, LucidType
dictation that showed no text, and Open WebUI models reading their tool calls aloud. It is a
**beta for testers** on Windows; macOS and Linux stay on v0.9.8.

## What changed since v0.9.8

### AI Voice hears fewer things you didn't say

A keyboard clack or a knock on the desk could reach Whisper as a clip of its own, and Whisper
answers near-silence with stock phrases: "Thank you.", "Cool.", "Thank you so much." Two changes:

- The voice detector now counts only the time that contains sound, so a click or knock is no
  longer taken for speech. A soft one-word "yes" or "no" still is.
- Clips made only of Whisper's stock phrases are dropped. In **AI Voice** that includes "thank
  you", "thanks", "bye" and "cool". In **LucidType** and **Live Translate** it is only what is never
  real speech (video credits, a lone "you", "um"), so a dictated "Thank you." stays. "Yeah" and
  "okay" are never dropped, because they answer the assistant's questions.

### LucidType says why no text is appearing

Dictation could show **DICTATING** over an empty box with no explanation. The LucidType header now
says what is wrong, in red for errors and yellow for warnings:

- the microphone failed to open, or the saved mic wasn't found and another one is in use
- nothing has been heard from the mic after a few seconds (muted, too quiet, or the wrong device)
- the speech server didn't answer
- the microphone capture couldn't start

LucidType also recovers on its own when its hidden capture window has crashed or stopped
responding: it rebuilds the window and starts again. Each step is recorded in `main.log`.

### Open WebUI models with tools now run them

With a workspace model that has tools or skills attached in Open WebUI, such as **ERP Admin**,
**AI Voice** showed and spoke the model's raw tool calls (`<tool_call>`, `titan_query`) instead of
running them. Those turns now go through Open WebUI's server-side tool calling: the tools run with
your API key's permissions and you get the answer. On these turns the reply appears all at once,
not word by word. Models without tools stream as before; if one writes a tool call as text anyway,
it is hidden and the status line says why it couldn't run.

On **Settings → Auth**, enter the model's ID, not its display name. The ID is shown in grey next to
the name under Workspace → Models in Open WebUI (for example `basis-admin` for ERP Admin).

### Claude Code says how to sign back in

When the Claude Code CLI's sign-in expires, **AI Voice** now adds the fix to the error: open a
terminal on the PC, run `claude`, then type `/login`.

### Also since v0.9.8

- **Settings → Meeting:** **Limit window picker to apps** (slide capture) and both **Call apps**
  lists are now filled from a running-apps picker, or by typing a name and pressing **Add**.
- **Drop-in apps** installed from the old `open-quake` repository address receive updates again.
- **arr-dash 1.1.0** ships via app updates: a needs-attention feed, stuck and failed downloads,
  and season packs grouped together.

**Download:** `bedrock-panel-setup.exe` (installer) or `bedrock-panel-portable.exe`. This beta is
not offered as an automatic update; install it by hand.

## What to try

- **AI Voice** with the mic on: type, tap the desk, and stay quiet for a while. Nothing should be
  sent. Then answer a question with a quiet "yes"; it should go through.
- **LucidType**: dictate a few sentences, then "Thank you." on its own; all of it should appear. If
  nothing appears, read the header. Try it with the saved mic unplugged or muted.
- **AI Voice** on **ERP Admin**: ask something that needs a lookup, such as an employee ID. The
  answer should arrive after the tools run, with no tags shown or read aloud. Interrupt one
  mid-lookup and confirm the panel is free again.

## Known limits in this beta

- **Steady background sound** (nearby conversation, continuous typing) can still be taken for
  speech. The detector goes by loudness, not by voice.
- **Open WebUI tool turns are not streamed**, so a long answer takes a while to start. Each turn
  uses a temporary Open WebUI chat that is deleted afterwards.
- **The IF Player community app** has its own copy of the voice detector and doesn't get the
  click fix.

## Reporting
