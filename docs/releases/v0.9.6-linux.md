# v0.9.6 — the Linux section

Written to be folded into the combined 0.9.6 notes. Everything here is new in 0.9.6; there was no
Linux build before it.

## Bedrock Panel runs on Linux

Software mode and Panel mode on the DK-QUAKE's 1920×480 display, the knob and the touchscreen, the
tile grids, the editor, dashboards, and every platform-neutral app. Packages are a `.deb` for Debian
and Ubuntu and an `AppImage` for everything else.

The panel window is placed through XWayland. A Wayland client cannot put a window at global screen
coordinates, and Panel mode is nothing but placement, so the app relaunches itself onto X11 at
startup and says so in the log.

## Speaking and listening, built in

No server, no GPU, no account, and nothing to compile. Piper speaks and sherpa-onnx listens, both
served on the standard Wyoming ports, so a server of your own on 127.0.0.1:10200 or :10300 still
wins if you have one.

- **90 voices in 36 languages**, each one public domain, CC0, CC BY or MIT, with the licence shown
  beside it. Pick a language, then a voice, and press Preview to hear it before downloading.
- **Listening comes as a ladder**: 28 MB English-only for dictation, or multilingual models from
  111 MB up. Live Translate needs a multilingual one, and says so.
- **Meeting transcription names people.** Speakers are separated by voice, and anyone enrolled once
  is named thereafter. LucidType dictation and the AI Voice apps, barge-in included, use the same
  engine.

## Input

- **Macros, media keys and typed text** through a uinput virtual keyboard. The deb installs the
  device-access rule itself; the editor walks everyone else through it.
- **Global hotkeys** through the XDG GlobalShortcuts portal, bound by one dialog rather than a trip
  to the desktop's settings.
- **Monitor mode** drives the cursor through a uinput absolute pointer.

## What the desktop already publishes

- **Now playing**, with cover art and buttons that control the player being shown. It reads MPRIS,
  the same thing the desktop's own media applet reads, so Firefox, Chromium, Spotify, VLC, Plex and
  Elisa all appear.

  One thing worth knowing, because it will bite anyone packaging an app for Ubuntu: since 24.04 an
  application needs an AppArmor profile before its sandbox may create user namespaces, and the
  profile electron-builder installs gives the process a *name*. A snap-packaged player accepts media
  traffic only from senders labelled `unconfined` or `plasmashell`, so the moment the app had a name
  every snap refused it — silently, as an AccessDenied nobody was printing. Where the app finds
  itself labelled, the reading now happens in a child that sheds the label on its way in.
- **The meeting console's output rail** shows the real system volume and follows the output you
  switched to.
- **Auto-record and the busy light** notice when an application takes the microphone. On Linux the
  names to list are program names like `zoom` or `chromium` rather than Windows `.exe` names.

## Known limits

- **Reserved Display**, **follow the focused app** and **reading a calendar on this computer** are
  not available and are greyed out with the reason beside them. Wayland does not allow moving or
  watching other applications' windows. The Microsoft 365 calendar source works everywhere.
- **Outlook desktop meeting info** is Windows-only.
- **A person must be enrolled before a meeting transcript can name them.** Until then they are
  separated and numbered, and someone who speaks for under five seconds in a whole meeting is not
  reported as a participant.
- **A display scaled to anything other than 100% is untested** with Monitor mode.
- **mpv publishes no MPRIS** unless the `mpv-mpris` plugin is installed, so the Music page stays
  blank for it.
- **The AppImage needs FUSE 2** — install `libfuse2t64`, or use the `.deb`.
- **x64 only.** There is no arm64 Linux build yet.

## Tested on

Ubuntu 26.04, KDE Plasma 6.6 on Wayland, PipeWire, x64, with a real DK-QUAKE. Other desktops, X11
sessions and other distributions are expected to work and have not been exercised.
