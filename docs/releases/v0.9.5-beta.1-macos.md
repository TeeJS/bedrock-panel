# Bedrock Panel v0.9.5-beta.1 — first macOS beta (Apple Silicon)

Bedrock Panel now runs on a Mac with the DK-QUAKE: knob, touchscreen, Panel mode on the 1920×480
display, Reserved Display, meeting recording and transcription, the Music page, and the AI Voice
pages — with speech handled by macOS itself. This is a **beta for testers**: it is signed with a
self-signed certificate (not notarized), so macOS asks you to allow it once, and a few permissions
have to be granted by hand. Everything below is verified on macOS 26 on an M-series MacBook Pro.

**Download:** `bedrock-panel-arm64.dmg` (Apple Silicon, macOS 14.2 or newer). The zip is the same
app without the disk image. Windows builds are unchanged in this beta (v0.9.4 remains current).

## First launch — five minutes, once

The whole walkthrough, with every System Settings pane named, is in **docs/macos.md**. In short:

1. Drag Bedrock Panel to Applications and launch it. macOS says it could not verify the app: click
   **Done**, then System Settings → Privacy & Security → scroll to *Security* → **Open Anyway**.
2. Click **Always Allow** in the keychain dialog ("bedrock-panel Safe Storage").
3. **Touchscreen:** the app opens System Settings → Privacy & Security → **Input Monitoring** and
   says so on the panel. Click **+**, pick Bedrock Panel from Applications, turn it on. The
   touchscreen connects within a few seconds. (macOS shows no prompt for this on some Macs, so the +
   step is expected.)
4. **Accessibility** (Reserved Display, keystroke tiles, macros): same **+** in the Accessibility pane.
5. **Microphone** and **Screen & System Audio Recording → System Audio Recording Only** for
   meeting recordings, when macOS asks.

Grants stick across updates from now on: every beta build carries the same signing certificate.

## What to try

- **Panel mode on the Quake** — the panel covers the display above the menu bar and Dock; mouse
  and keyboard work on it like on Windows (Settings → Device → Monitor lets you make it touch-only).
- **Starter pages** — a fresh install starts with Mac pages (Safari, Finder, Notes, Calculator,
  Activity Monitor, Terminal, System Settings, Screenshot, Mission Control, Music, Calendar,
  Messages, volume tiles). An existing config: editor → **+ Add page → Starter pages…**.
- **Reserved Display** (on by default) — drop any window on the Quake; it comes back to your main
  display. The app also keeps the Quake at the far right of the display arrangement, never
  mirrored and never the main display, the same rule the OEM software applies.
- **Meeting recording** — Meeting page → record; the transcript is made **on your Mac** with
  Apple's on-device speech (your microphone = you, system audio = everyone else), then the AI notes.
- **AI Voice** — Claude / Codex / Copilot CLIs found automatically when installed; speech
  recognition and voices are macOS's own (Settings → Integrations → TTS/STT).
- **Music page** — Apple Music and the Spotify desktop app are shown; transport buttons ask for the
  Automation permission the first time.

## Known limits in this beta

- Not notarized: the *Open Anyway* step on first launch after each download.
- **Live speech recognition needs Dictation on** (System Settings → Keyboard → Dictation); file
  transcription does not.
- Spotify **Web** in a browser is not visible to the Music page (no public macOS API); the Spotify
  desktop app is.
- A DisplayLink adapter shows macOS's purple screen-recording dot on the panel; it is not the app's.
- Windows-only for now: Outlook desktop meeting info (use the Microsoft 365 source), the
  touchscreen wizard, album-art thumbnails from the media session, and the community apps that
  need Windows executables.
