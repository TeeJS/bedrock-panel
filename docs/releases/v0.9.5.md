# Bedrock Panel v0.9.5 — Windows and macOS

The first release that ships for both: the Windows build as before, and the DK-QUAKE on a Mac with
Apple silicon. The macOS build is signed with a Developer ID and notarized, so it installs like any
other Mac app.

**Downloads**
- `bedrock-panel-setup.exe` — Windows x64 installer · `bedrock-panel-portable.exe` — Windows x64, no install
- `bedrock-panel-arm64.dmg` — macOS 14.2 or newer on Apple silicon (the `.zip` is the same app)

## macOS

Everything the Windows app does with the panel, on a Mac: knob, touchscreen, Panel mode covering
the 1920×480 display above the menu bar and Dock, Reserved Display (windows that land on the panel
go back to your main display; the panel stays at the far right of the arrangement, never mirrored,
never the main display), meeting recording with system audio, and the AI Voice pages.

- **Speech is macOS's own.** Recognition runs on the Mac with Apple's SpeechAnalyzer (macOS 26; no
  Dictation setting, no prompt, each language's model downloads once) and the system voices speak
  the replies — nothing to install. The TTS/STT settings list the voices by language, with a
  **Preview** button and a **Rescan** for voices downloaded later. A Whisper/Piper server still works
  when you have one.
- **Meeting transcripts are made on the Mac** with the same engine; the recorder's stereo layout
  (your microphone left, everyone else right) gives the speakers.
- **Meeting info from your calendar:** the new **macOS Calendar** source reads today's meeting from
  any account under System Settings → Internet Accounts; **Microsoft 365** stays the choice when
  the work account cannot be added there (Outlook for Mac shares no calendar with other apps).
- **Zoom and Teams buttons:** Teams uses its Mac shortcuts; Zoom's Mute, Video, Leave, Share and
  Full screen press Zoom's own menu and toolbar controls through Accessibility, with Zoom left in
  the background.
- **Music page** shows Spotify (desktop app) and Music, including a player that was already
  playing when the app started.
- **Starter pages** on a fresh install: Default, Media, and Dev, built from apps every Mac has.
- Permissions are granted once and kept across updates. The first launch asks for **Input
  Monitoring** (the touch controller; macOS shows no prompt for it, so the app opens the pane and
  the entry is added with **+**), **Accessibility**, then **Microphone**, **System Audio
  Recording**, **Calendars**, and **Automation** as the features are first used. The full
  walkthrough is [docs/macos.md](../macos.md).

## Both platforms

- **Live Translate:** a **Spoken language** row on the page's Settings card. Whisper and Soniox
  detect the language when it is left on Auto; the Mac's built-in engine needs it set. The
  interpreter is told the language too.
- **oMLX Monitor**, a new drop-in app: loaded models with memory and requests in flight, tokens per
  second, memory pressure, and one-tap Load / Unload for oMLX servers (Settings → Drop-In Apps →
  Browse).
- Every Zoom/Teams button press is logged with its outcome in `main.log`.

## Known limits

- macOS: Spotify Web, YouTube Music, and other browser players are not visible to the Music page;
  the touchscreen wizard, media-session album art, and the Windows-only community apps stay
  Windows-only. A DisplayLink adapter shows macOS's own purple screen-recording dot on the panel.
- macOS: the built-in recognizer covers German, English, Spanish, French, Italian, Portuguese,
  Japanese, Korean, Chinese, and Cantonese; other languages fall back to Apple's older recognizer,
  which needs Dictation on.

## Upgrading

- **Windows:** install over the previous version; nothing changes in the config.
- **macOS from a beta:** the signature changed, so the privacy grants are asked once more (remove
  the old **Bedrock Panel** entry under Input Monitoring and add it again with **+**), and the
  keychain dialog appears one last time — click **Always Allow**. After that, updates ask nothing.

Reports: include `main.log` (`%APPDATA%\bedrock-panel` on Windows, `~/Library/Logs/Bedrock Panel/`
on macOS) and your OS version. Issues: https://github.com/TeeJS/bedrock-panel/issues
