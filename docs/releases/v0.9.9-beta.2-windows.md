# Bedrock Panel v0.9.9-beta.2 — Windows beta: the right microphone

This beta fixes the microphone choice found while testing beta.1: LucidType and web pages were
using the Windows default mic instead of the one chosen in Bedrock Panel. It is a **beta for
testers** on Windows; macOS and Linux stay on v0.9.8.

## What changed since beta.1

### LucidType listens on the mic its settings show

With **Settings → General → Audio** set to one mic and Windows' default set to another, LucidType
showed the right mic in its settings but listened on the Windows default. Its new header message
gave it away: "Nothing heard from Default - Microphone (…)". LucidType now opens the mic Bedrock
Panel names, and if that mic is unplugged the header says it couldn't be found and which mic it is
using instead.

**AI Voice** and **Live Translate** also find a saved mic more reliably now, even when Windows lists
it as "Default - …" or under a slightly different name.

### Web pages use Bedrock Panel's mic

Web pages on the panel, such as a voice app on your own server, always got the Windows default mic.
Now a page that asks for "a microphone" gets the default from **Settings → General → Audio**. To use
a different mic for one page, turn on **Advanced settings → Audio → Override default audio sources**
on that page and pick it. A page with its own mic picker keeps its own choice. A change applies the
next time the page loads.

Everything from beta.1 is still here: fewer phantom turns in AI Voice, LucidType saying why no text
appears, Open WebUI tools that run instead of being read aloud, and the Claude Code sign-in hint.

**Download:** `bedrock-panel-setup.exe` (installer) or `bedrock-panel-portable.exe`. Like beta.1,
this beta is not offered as an automatic update; install it by hand.

## What to try

- **LucidType** with Windows' default mic set to a different device than Bedrock Panel's: dictate,
  and the text should appear. Unplug the chosen mic and start again: the header should name the mic
  it couldn't find.
- **A web page that uses the mic** (LibraVox): it should listen on Bedrock Panel's mic. Turn on its
  Audio override with another mic, reload the page, and it should switch.
- **AI Voice** and **Live Translate** still pick the mic shown in their settings.

## Known limits in this beta

- **A web page picks up a mic change on its next load**, not while it is open.
- **The first time a web page asks for the mic**, the Windows default may light up for a moment
  before Bedrock Panel's mic takes over.
- Everything listed for beta.1 still applies: steady background sound can be taken for speech, Open
  WebUI tool turns are not streamed, and the IF Player community app has its own voice detector.
