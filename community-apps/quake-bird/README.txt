Quake Bird
==========

A flappy-style arcade game for the Bedrock Panel panel. Tap anywhere to flap
(Space / Up-arrow on a desktop window), thread the bird through the pipe
gaps, and chase your best score. Pipes speed up and the gap tightens as
you score. The speaker button in the top-right corner (or the M key)
mutes the sound; the choice is remembered.

- Pipes take your page's accent color; day/night follows the page theme.
- Best score is saved on the device.
- The game pauses automatically when the page is hidden.

Shared high scores (optional): the first time you finish a scoring
flight, the game asks for your initials (1-3 letters) on an on-screen
arcade keyboard (change them later via the INITIALS button on the title
screen). Personal bests upload to the shared score server -- the title
screen shows the global best, and game over shows how your flight ranked
plus the top-5 leaderboard. The Player initials app option, when set,
overrides the in-game initials. The Server URL is an advanced option; clear it to play fully
offline. The game never blocks on the network.

Install: Settings -> Drop-In Apps -> Browse the app repository and
install Quake Bird, then add a page with the Quake Bird app.

All artwork is original, drawn in canvas at runtime. This is a fan-style
homage; it contains no assets from, and is not affiliated with, the
original Flappy Bird by Dong Nguyen / .GEARS.
